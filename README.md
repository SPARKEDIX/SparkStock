## ✨ Features

| Feature | Description |
|---|---|
| 📈 **Real-Time Stock Data** | Live price feed with auto-refresh |
| 🤖 **AI Buy/Sell Signals** | ML model-based trading recommendations |
| 📊 **Interactive Charts** | Candlestick, OHLC, Volume analysis |
| 🔍 **Technical Indicators** | RSI, MACD, Bollinger Bands, SMA/EMA |
| 📰 **Sentiment Analysis** | News-based market sentiment scoring |
| 🔔 **Price Alerts** | Custom threshold-based notifications |
| 🌍 **Multi-Market Support** | NSE, BSE, NASDAQ, NYSE |
| 📱 **Responsive UI** | Works on desktop & mobile |

## 🎯 Problem Statement

Retail investors in India and globally lack access to:
- **Real-time intelligent insights** without paying for expensive Bloomberg terminals
- **AI-powered analysis** that big hedge funds use
- **Simple, intuitive interfaces** — existing platforms are cluttered and confusing

**SparkStock bridges this gap** — bringing institutional-grade intelligence to everyday investors, for free.
